Configuration, audit, and reference projects for one CachyOS desktop — a Beelink GTR9 Pro (Ryzen AI Max+ 395, Radeon 8060S) — and the devices around it.

## CachyOS on the GTR9 Pro

| Repository | What it is |
|---|---|
| [ry-install](https://github.com/ryanmusante/ry-install) | Fish script that deploys the tuned CachyOS profile: managed configs, packages, units, fstab |
| [ry-verify](https://github.com/ryanmusante/ry-verify) | Read-only audit of the profile ry-install deploys |
| [ry-dashboard](https://github.com/ryanmusante/ry-dashboard) | Terminal monitor that colors live values against the deployed profile |
| [cachyos-gtr9-iso](https://github.com/ryanmusante/cachyos-gtr9-iso) | Build kit for a CachyOS ISO that installs the configured host |
| [gtr9pro-bios-reference](https://github.com/ryanmusante/gtr9pro-bios-reference) | Every BIOS Setup option of the GTR9 Pro firmware, decoded |
| [gtr9-postboot-log-analysis](https://github.com/ryanmusante/gtr9-postboot-log-analysis) | PDF report builder for a bug-report log and a ry-verify log |
| [cachyos-tuning-audit](https://github.com/ryanmusante/cachyos-tuning-audit) | Research audit companion for the tuning profile |
| [cachyos-kvm-configuration](https://github.com/ryanmusante/cachyos-kvm-configuration) | Procedure for an isolated CachyOS KVM guest on the same host |
